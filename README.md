# Emmanuel Uba — Portfolio V2

A buildless, responsive website in `dist/`. Open `dist/index.html` directly, or run `python -m http.server 4173 --directory dist` from this directory and visit http://localhost:4173.

Features: responsive dark design, SVG neural signal propagation, pointer-based 3D cards, four accessible case-study dialogs, floating profile preview, profile-summary download, section navigation, motion pause, and system reduced-motion support. Native dialogs support Escape, focus trapping, and return focus. No app dependencies; optional Google Fonts have local fallbacks.

Content is based on the referenced portfolio discussion. No V1 source archive was accessible. Case studies explicitly separate reported project context from proposed architecture and verification plans. No measured outcomes are invented. R, Julia, Haskell, SQL, APIs, databases, CI/CD, and cloud deployment remain unverified learning candidates. The résumé interface delivers a draft text summary, not a final résumé PDF. Direct contact details and verified repository links were unavailable.

Edit `dist/index.html` for page content, `dist/app.js` for case studies and interactions, and `dist/style.css` for design. Update the summary alongside page content. A final résumé and confirmed contact links are the next content milestone.
